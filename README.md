# Python 期末大作业：康威生命游戏 (Game of Life)

这是一个基于 Python 原生 Tkinter 库开发的图形化小游戏。本项目不仅实现了经典的“康威生命游戏”细胞繁衍规则，还加入了鼠标绘图、随机生成以及文件存档等实用功能。

---

## 💡 项目功能特点

1. **图形化界面 (GUI)**：告别黑白控制台，使用 Tkinter 绘制了直观的网格界面，绿色方块代表活细胞，黑色代表死细胞。
2. **鼠标交互绘图**：支持直接在画布上用鼠标点击或拖拽，像画画一样自由布置初始的细胞阵型。
3. **无边界模式**：利用取模运算（`%`）处理了边界问题。当细胞飞到屏幕最右边时，会自动从屏幕最左边穿出来（类似《吃豆人》游戏），不会出现数组越界报错。
4. **存档与读档功能**：可以将当前屏幕上好看的细胞图案，保存为本地的 `.txt` 文本文件；下次运行可以直接读取恢复。

---
